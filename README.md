# Cybersecurity Learning Prompt Library

### By Scott Malin — Cybersecurity & Automation Architect

Interactive, gamified cybersecurity learning experiences that build intuition, sharpen reasoning, and teach security concepts through hands‑on exploration and challenge.

---

## ⭐ Featured Learning Experience

### **Cyberscam Survival Simulator.md**

**Goal:** Teach users to identify, resist, and analyze social engineering attacks through an adaptive, branching simulation.

**What you’ll experience:**
- Realistic scam scenarios with escalating pressure  
- Decision‑driven outcomes that adapt to user choices  
- Embedded reasoning challenges that reinforce safe behavior  

### **Cybersecurity Socratic Mentor.md** (v2.0.1)

**Goal:** Mentor beginner and junior learners with Socratic escalation, evidence-based reasoning, no fabrication, documentation-first practice, and lab-safety rules. Added September 2026; trimmed in v2.0.1 for clarity without dropping core safeguards.

## 🎓 Featured Workshop

### **Signal vs Noise – Team Adversarial Judgment Workshop.md**

**Goal:** Train teams to collaboratively distinguish meaningful security signals from irrelevant noise through structured adversarial reasoning.

**Best for:**
- Security teams  
- SOC analysts  
- Red/Blue/Purple team exercises  
- Classroom or corporate training environments  

**Participants will:**
- Identify true indicators of compromise  
- Challenge assumptions and justify reasoning  
- Communicate uncertainty effectively  
- Collaborate under time pressure  

Pairs well with the **Adversarial Judgment Trainer** for pre‑work or follow‑up practice.

## 📘 Overview

This repository provides a curated library of cybersecurity learning prompts designed to:

- Build intuition through interactive reasoning  
- Teach concepts through guided exploration  
- Simulate real‑world attack and defense scenarios  
- Support facilitator‑led and self‑paced learning  
- Strengthen communication skills across technical and non‑technical audiences  
- Provide repeatable, structured cybersecurity education  

Ideal for:

- Security awareness programs  
- Classroom or workshop facilitation  
- Corporate training  
- Personal skill development  
- Interview preparation  
- Gamified learning environments

## 🧭 Who This Is For

- Cybersecurity learners at all levels  
- SOC analysts and security teams  
- Educators, trainers, and facilitators  
- Corporate learning and development groups  
- Individuals preparing for interviews or certifications  

---

## 🧱 Learning Design Principles

- Interactive first — learning through doing  
- Reasoning over recall — focus on judgment, not memorization  
- Human‑centric — emphasize communication, behavior, and decision‑making  
- Facilitator‑ready — built for workshops and team exercises  
- Modular — each file stands alone or can be combined into learning paths  
- Session-stable — September 2026 updates lock state, HUD/output templates, and jailbreak handling for long games  

---

## 🧰 How to Use This Repository

Use these prompts to run workshops, facilitate training sessions, build custom learning paths, or practice cybersecurity reasoning individually. Each file includes a clear goal statement and is structured for repeatable use.
